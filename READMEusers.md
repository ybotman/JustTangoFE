# User Roles Overview

1. Most Users:

	•	General Access:
	•	No login required to browse events.
	•	Can view events, filter them, and possibly receive notifications.
	•	Optional Login:
	•	If logged in, users can configure notifications and preferences.

2. Organizers:

	•	Required Login:
	•	Must log in to manage their events.
	•	Can add, change, delete, extend, and cancel their events.
	•	May have the option to pay for promoting their events in future updates.
	•	Guest Access:
	•	Without logging in, they function as regular users.

3. Regional Admins:

	•	Specialized Organizers:
	•	Assigned to manage a specific region.
	•	Can add new regional organizers.
	•	Can manage regional locations.
	•	Can elevate issues or requests to System Admins.
	•	Can request System Admins to modify any event in their region.

4. System Admins:

	•	Highest-Level Admins:
	•	Can add new regional admins.
	•	Can create new regions.
	•	Can remove non-compliant events.
	•	Responsible for managing financial aspects like campaigns and ads.
	•	Might require a more secure login method, such as an authentication app.
